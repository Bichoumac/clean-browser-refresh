Clean Browser Refresh

Refreshes the page without its URL parameters: https://site.com/page?utm_source=x&id=42 → https://site.com/page

Keyboard shortcut

—

Combine Ctrl, Alt or Cmd with a key (Shift optional), or use a single F1–F12 key (F5 for example). Some shortcuts reserved by the browser (Ctrl+T, Ctrl+W, Ctrl+N…) cannot be intercepted.

Options

Other triggers

Clicking the extension icon does the same thing. You can also set a native browser shortcut (works even on pages where the shortcut above cannot run): chrome://extensions/shortcuts in Chrome, or about:addons → ⚙ → “Manage Extension Shortcuts” in Firefox.
